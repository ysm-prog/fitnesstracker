# New Feature Workflow

1. Read project instructions and existing feature patterns.
2. Clarify business outcome and acceptance criteria.
3. Inspect affected modules and data flow.
4. Identify security, data, UX, performance, and testing implications.
5. Propose the smallest coherent design.
6. Implement incrementally.
7. Add or update tests.
8. Run type checks, lint, tests, and build checks available to the project.
9. Update documentation when needed.
10. Summarise changed files, verification, assumptions, and remaining risks.

Use `business-analyst`, `solution-architect`, `frontend-architect`, `backend-architect`, `database-architect`, `security-engineer`, `qa-engineer`, and `ux-reviewer` selectively based on the feature.

Apply `.claude/standards/architecture.md`, `.claude/standards/coding.md`, `.claude/standards/security.md`, `.claude/standards/testing.md` and `.claude/standards/ux.md` throughout.
