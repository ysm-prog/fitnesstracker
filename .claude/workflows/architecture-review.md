# Architecture Review Workflow

1. Read project context and existing architecture documentation.
2. Map affected modules, dependencies, data flow, and integrations.
3. Review maintainability, security, performance, data ownership, and operability.
4. Identify duplication, coupling, unclear boundaries, and unnecessary complexity.
5. Compare realistic alternatives.
6. Recommend a target state and migration sequence.
7. Record significant decisions as an ADR.
8. Do not implement a broad rewrite until the target state and migration plan are agreed.

Apply `.claude/standards/review.md`, `.claude/standards/architecture.md` and `.claude/standards/performance.md` throughout.
