# Release Workflow

1. Confirm intended scope and version.
2. Review migrations, compatibility, configuration, secrets, and external dependencies.
3. Run appropriate automated checks.
4. Define smoke tests and rollback or forward-fix approach.
5. Confirm monitoring and operational visibility.
6. Prepare concise release notes.
7. Verify the deployed behaviour rather than assuming a successful build means a successful release.

Apply `.claude/standards/operations.md`, `.claude/standards/testing.md`, `.claude/standards/database.md` and `.claude/standards/security.md` throughout.
