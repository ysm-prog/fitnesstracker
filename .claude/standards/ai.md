# AI Engineering Standard

- Treat model output as probabilistic.
- Keep prompts versionable and separate from business logic where practical.
- Validate structured AI output before using it in important workflows.
- Define fallback behaviour for model failures.
- Minimise sensitive data sent to models.
- Review prompt-injection and untrusted-context risks.
- Measure quality, latency, and cost for important AI workflows.
- Keep provider-specific code behind clear boundaries when multiple providers may be needed.
